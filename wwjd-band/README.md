# WWJD 織りブレスレットを個人で作る(手編みDIY)

写真のような布製 **WWJD バンド**("What Would Jesus Do" の文字がドット状に
織り込まれ、スライダーで長さ調整するタイプ)を、個人で1本ずつ手作りするための
図案とガイドです。文字部分はミサンガの「アルファパターン」方式で再現します。

> Google Fitbit Air のカスタムバンド(シリコン/3Dプリント)とは別物です。
> こちらは布・刺繍糸でつくる編みブレスレットです。

## 中身

| ファイル | 用途 |
|---|---|
| `wwjd_alpha_pattern.py` | 「W.W.J.D」のドット図案を1枚生成(色・文字を引数で変更可) |
| `wwjd_colorways.py` | 写真のような色違い一覧(コンタクトシート)を生成 |
| `wwjd_pattern.png` | 既定の図案(青×白) |
| `wwjd_colorways.png` | 色違いラインナップ |

### 図案を作り直す

```bash
pip install matplotlib

# 既定(青文字×白地)
python3 wwjd_alpha_pattern.py

# 文字・色を指定: 引数 = テキスト, 文字色, 地色
python3 wwjd_alpha_pattern.py "W.W.J.D" "#ffffff" "#ff5aa0"   # ピンク地×白文字

# 色違い一覧
python3 wwjd_colorways.py
```

## 必要な道具(買い物リスト)

- **刺繍糸 2色**(地色・文字色)… DMC25番など。1本あたり地色を多めに
- **コードストッパー/スライダー** 1個/本 … 長さ調整の留め具(手芸・ビーズ店)
  - 無ければ端を三つ編みして結ぶ仕上げでもOK
- マスキングテープ or セーフティピン or クリップボード(編み始めの固定用)
- ハサミ、メジャー(手首周り計測)
- (任意)ビーズ織り機 … 機械織りに近い均一な仕上がりにしたい場合

## 図案の読み方

- 図は **9列 × 59段** のドットグリッド。**色付きマス=文字**、**地色マス=背景**。
- バンドは縦方向に進み、上から `W → W → J → D`(間にドット区切り)。
- 1マス = 1ノット(結び目)。アルファパターンでは横の糸数 ≒ (列数+1) 程度が目安。

## 作り方(アルファパターン方式・概略)

1. **長さを決める**:手首周り + 留め具分。糸は仕上がり長さの約4倍を用意。
2. **縦糸(地色)を並べる**:図案の列数に合わせて地色の糸を張り、上端をテープで固定。
3. **横糸で1段ずつ結ぶ**:横糸を左→右に通しながら各縦糸に結ぶ。
   - そのマスが **地色** なら通常どおり地色で結ぶ。
   - **文字色** のマスでは、横糸を裏に回して**文字色の糸**で結び、表に文字色を出す。
   - 図案の1段=ブレスレットの1段。上の段から順に進める。
4. **段を繰り返す**:図案の59段を上から再現していくと W.W.J.D が浮かび上がる。
5. **仕上げ**:両端を始末し、スライダー(コードストッパー)を通して長さ調整可能にする。

> 初めてなら、まず短いテスト片で1文字(例: D)だけ編んで、文字色の出方と
> テンションを確認してから本番に入ると失敗が少ないです。

## 色違いを作りたい

`wwjd_colorways.py` の `COLORWAYS` リストに `(文字色, 地色, ラベル)` を追加すれば
任意の配色を一覧出力できます。写真と同じピンク/黒/赤/緑/紫/橙/黄/灰などを収録済み。
