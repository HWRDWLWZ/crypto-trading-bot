# WWJD バンド制作キット

WWJD バンドを個人で作るための図案・設計データ。2つのバリエーションがある。

- **A. 飾りバンド(布・手編み)** … 写真のような WWJD 織りミサンガ。デバイスは挟まない。
- **B. Fitbit Air 機能バンド** … Fitbit Air のセンサーペブルを保持する WWJD 柄バンド(3Dプリント)。

---

## A. 飾りバンド(手編みDIY)

文字がドット状の WWJD 織りブレスレットを、ミサンガの「アルファパターン」方式で作る。

| ファイル | 用途 |
|---|---|
| `wwjd_alpha_pattern.py` | 「W.W.J.D」のドット図案を生成(色・文字を引数で指定) |
| `wwjd_colorways.py` | 写真のような色違い一覧を生成 |
| `wwjd_pattern.png` / `wwjd_colorways.png` | 生成済み図案 |

```bash
pip install matplotlib
python3 wwjd_alpha_pattern.py "W.W.J.D" "#ffffff" "#ff5aa0"   # ピンク地×白文字
python3 wwjd_colorways.py
```

### 必要な道具
- 刺繍糸2色(地色・文字色)/ コードストッパー(スライダー留め具)/ テープ・ハサミ

### 作り方(概略)
1. 手首周り+留め具分で長さを決め、糸は約4倍用意
2. 地色の縦糸を張って固定
3. 横糸で1段ずつ結ぶ。図案の**色付きマス=文字色**、**地色マス=地色**で結ぶ
4. 59段を上から再現すると W.W.J.D が出る
5. 端を始末しスライダーを通して長さ調整可能に

> まず短いテスト片で1文字だけ編んで、文字色の出方とテンションを確認すると失敗しにくい。

## B. Fitbit Air 機能バンド(センサーペブルがはまる)

Fitbit Air のセンサーペブルを「スリーブ」で保持する WWJD 柄バンド。TPU で3Dプリント。

| ファイル | 用途 |
|---|---|
| `wwjd_fitbit_band.scad` | スリーブ + WWJD バンドのパラメトリック設計(OpenSCAD) |
| `fitbit_sleeve_section.py` / `fitbit_sleeve_section.png` | スリーブ断面の概念図 |

### 確定寸法(Google 公式ブループリント D-0001799540 由来)

| 部位 | 寸法 | 公差 |
|---|---|---|
| ペブル 長さ(長軸) | 33.5 mm | ±0.1 |
| ペブル 幅(短軸・最大膨らみ) | 14.36 mm | ±0.08 |
| ペブル 断面 | くびれ形状(上下が膨らみ中央が溝) | — |
| スリーブ内開口 長さ | 32.76 mm | +0.07 |
| スリーブ内開口 幅(リップ部 section B-B) | 13.77 mm | +0.06/−0.15 |
| リップ詳細 | 2.1 / 1.3 / 0.65±0.15 / 1.05±0.15 mm | — |
| 装着力 / 取り外し力 | 10–25N / 12–45N | — |

### 嵌合の原理
スリーブ開口(**32.76 × 13.77**)はペブル最大(**33.5 × 14.36**)よりわずかに小さい。
柔軟な TPU スリーブがペブルの膨らみを乗り越え、**くびれ溝にリップが噛んで保持**する。
この差(長手約0.74 / 幅約0.59mm)が 10–25N/12–45N の着脱力を生む。

### まだ確定していない値(要実測)
- **ペブル高さ(厚み)**:入手した図面シートに数値が無い。実機をノギスで測って
  `wwjd_fitbit_band.scad` の `peb_h` に入れる。
- くびれ溝の Z 位置(リップが噛む高さ)も同様に実測で詰める。

### 制作・調整の順番
```bash
# OpenSCAD で wwjd_fitbit_band.scad を開く → F6 → Export STL → TPUで印刷
```
1. **スリーブだけ**を TPU で印刷し、実機ペブルで着脱力を確認
   - 緩い → `lip_h` を増やす / `sl_open_w` を小さく
   - 固すぎ → 逆に調整。目標 装着10–25N / 取り外し12–45N
2. `peb_h` を実測して入れ、ポケット深さを合わせる
3. 嵌合確定後に `len_a` / `len_b` を手首実測で調整し、バックル(closure)を追加

### 注意
- **センサー面(PPG/SpO2)を塞がない**こと(`win_l/win_w` の窓を確保)。肌に均一接触(約35mmHg)。
- **肌安全素材**を使う(ニッケル・天然ラテックスを避ける)。TPU はスキンセーフ等級を選ぶ。
- 公式図面 PDF は「Google Confidential」表記のためリポジトリには含めていない。
  本キットには**寸法(数値)のみ**を反映している。
